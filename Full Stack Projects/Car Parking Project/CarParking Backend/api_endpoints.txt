CAR PARKING SYSTEM - FULL API DOCUMENTATION
==========================================

BASE URL: http://localhost:8080

1. CAR REGISTRATION
===================

1.1 Get All Cars
----------------
Endpoint: GET /api/cars
Description: Retrieves a list of all registered cars.
Payload: None

1.2 Get Car by ID
-----------------
Endpoint: GET /api/cars/{id}
Description: Retrieves a single car's details.
Payload: None

1.3 Add New Car
---------------
Endpoint: POST /api/cars
Description: Adds a new car to the system.
Payload (JSON):
{
    "carNumber": "KA-01-HH-1234",
    "ownerName": "John Doe",
    "color": "White",
    "model": "Toyota Fortuner"
}

1.4 Update Car
--------------
Endpoint: PUT /api/cars/{id}
Description: Updates details of an existing car.
Payload (JSON):
{
    "carNumber": "KA-01-HH-1234",
    "ownerName": "John Doe",
    "color": "Black",
    "model": "Toyota Fortuner"
}

1.5 Delete Car
--------------
Endpoint: DELETE /api/cars/{id}
Description: Removes a car entry.
Payload: None


2. PARKING SLOT MANAGEMENT
==========================

2.1 Add Parking Slot
--------------------
Endpoint: POST /api/slots/add
Description: Creates a new parking space in the system.
Payload (JSON):
{
    "slotNumber": "A-101",
    "type": "CAR_SMALL",
    "hourlyRate": 40.0
}

2.2 Get Available Slots
-----------------------
Endpoint: GET /api/slots/available
Description: Lists all slots that are currently free (available = true).
Payload: None


3. BOOKING & PRICING (USECASE)
==============================

3.1 Parking Entry (Check-In)
---------------------------
Endpoint: POST /api/bookings/entry
Description: Records a car entering a specific slot. Sets status to 'ACTIVE'.
Payload (JSON):
{
    "carNumber": "KA-01-HH-1234",
    "slotId": "65ddf..." // MongoDB ID of the slot
}

3.2 Parking Exit (Check-Out)
----------------------------
Endpoint: POST /api/bookings/exit/{carNumber}
Description: Ends the booking, calculates fee based on hours used, and frees the slot.
Path Variable: carNumber (e.g., KA-01-HH-1234)
Payload: None (Triggered by car number)

Example Response:
{
    "id": "booking_id",
    "carNumber": "KA-01-HH-1234",
    "slotNumber": "A-101",
    "entryTime": "2024-02-27T10:00:00",
    "exitTime": "2024-02-27T12:15:00",
    "totalFee": 120.0, // Calculated as 3 hours * hourlyRate
    "status": "COMPLETED"
}


4. EXCEPTION HANDLING
=====================
The API returns structured error responses for common failures:

- 404 Not Found: If a slot id or car number (for exit) doesn't exist.
- 400 Bad Request: If trying to book a slot that is already occupied.
- 500 Internal Error: For unexpected server-side issues.

Error Body Format:
{
    "timestamp": "2024-02-27T08:00:00",
    "message": "Detailed error message here"
}
